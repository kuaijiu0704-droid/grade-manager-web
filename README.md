# 学生成绩管理程序（网页版）

面向对象编程 2 · 第三周作业 · 基于 GitHub Pages 部署

> 由第一周 C++ 控制台程序 `main.cpp` 迁移为可在浏览器中运行的网页程序。

## 程序介绍

这是一个学生成绩管理工具：录入学生人数与及格线（默认 60 分），逐名输入学生姓名与成绩（0~100），程序自动统计全班平均分、最高分及姓名、及格/不及格人数，并按成绩从高到低输出排名。

## 保留的 C++ 核心功能

- 录入学生人数与及格分数线（及格线留空时按默认 60 分处理）
- 成绩 0~100 整数校验，非法输入提示重新输入
- 统计平均分（保留两位小数）、最高分及学生姓名
- 统计及格人数与不及格人数
- 按成绩从高到低输出成绩排名

## AI 实现 / 改进

- 将控制台顺序问答流程重构为分区可视化界面（基本设置 / 信息录入 / 统计报告）
- 动态增删学生，名单随操作实时调整（对应 C++ 中 vector 的动态扩容）
- 即时输入校验与错误拦截
- 及格率进度条、第一名高亮、不及格成绩红色标识
- 示例数据一键填充与一键重置

## 使用说明

1. 打开网站后，在「基本设置」中填写学生人数与及格线，点击「生成录入表」（或直接「填充示例数据」快速体验）。
2. 在「学生信息录入」表格中逐行填写姓名与成绩；可随时追加或删除学生。
3. 点击「生成成绩报告」，查看统计卡片、及格率进度条与成绩排名。
4. 点击「重置」可清空全部内容重新开始。
